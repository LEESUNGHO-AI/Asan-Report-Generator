# 아산시 강소형 스마트시티 조성사업 — 공문서 생성 시스템 v5.0

기존 `Asan-Report-Generator`(통합 보고서 생성 시스템 v4.0)를 **국가보조금 사업 공문서 체계**로 전면 개편한 버전입니다.

- 발주처 : 아산시 도시계획과 스마트도시팀
- 수행기관 : ㈜제일엔지니어링종합건축사사무소 (직접보조사업자 · 총괄 PMO)
- 사업기간 : 2023. 12. 1. ~ **2026. 12. 31.** (사업연장 반영)
- 총사업비 : 240억원 (국비 50% · 시비 38% · 도비 12%)

## 2. v4.0 → v5.0 개편 내역

### 2.1 공문서 규격 (신규 `js/gongmun.js`)

| 항목 | v4.0 | v5.0 |

| 용지·여백 | A4 / 위 22.9·좌우 19.4mm | A4 / **위 30 · 아래 15 · 좌우 20mm** |
| 글꼴·줄간격 | 맑은 고딕 10.5pt | **맑은 고딕 12pt · 줄간격 160%** |
| 항목기호 | □ ○ - 만 사용 | **1. → 가. → 1) → 가) → (1)** 자동 생성 + 개조식 병존 |
| 금액표기 | `113.6억원` | **`금24,000,000,000원(금이백사십억원)`** 한글 병기 자동변환 |
| 날짜표기 | 혼용 | **`2026. 8. 25.`** 통일 |
| 두문 | 없음 | **기관명 · 수신 · (경유) · 제목** |
| 결문 | 없음 | **발신명의(직인) · 기안/검토/결재 · 시행/접수 · 우편·전화·전송·메일 · 공개구분** |
| 붙임 | `붙임. 세부 현황 자료` | **`붙임  1. ○○○ 1부.`** 연번·부수 표기 |
| 종결 | 없음 | **`끝.`** 자동 삽입 |
| 쪽번호 | 없음 | **`- 1 -`** 중앙 하단 |
| 결재란 | 표지 중앙 임의 배치 | **우측 상단 3칸(담당/검토/결재)** + 직위·성명 |

### 2.2 데이터 정합성

- **전 금액을 '원' 단위 원본으로 보존** (v4.0은 억원 환산 후 소수 1자리로 반올림 → 정산 시 원단위 불일치)
- **연도별 집행현황** 신설 (분기·연간 보고서)
- **중요재산 명세** 신설 — 취득가액 5천만원 이상 자동 추출 (현재 7건 검출)
- **재원별 집행액에 추정치 각주 자동 삽입**
  > v4.0은 `재원금액 × 전체집행률`로 안분한 값을 확정치처럼 표기했습니다. 정산·감사 시 실집행과 불일치가 드러나는 항목이므로, 표 하단 각주와 종합의견 권고사항에 자동 명시하도록 변경했습니다. **재원별 실계정 집행자료 연계가 근본 해결책입니다.**

### 2.3 참여인력 데이터 (별도 제공)

v4.0은 HR 포털 **HTML을 정규식으로 파싱**하여 기관별 합계만 취득하고, 인건비 정산에 필요한 명부는 전부 유실되었습니다.

- `tools/build-hr-json.js` — HTML → **`data/hr.json`(schema `hr.v1`)** 생성기
- `.github/workflows/hr-json.yml` — HR 포털 저장소용 자동 생성 워크플로
- `js/core.js` `processHR()` — **JSON 1순위 / HTML 2순위 폴백** 이중화
- 신규 산출 지표
  - `headcount` : 성명·직급 기준 **실인원** (역할 중복 제거)
  - `manRatio` / `activeManRatio` : **참여율 합계** → 인월(M/M) 환산 근거
  - `roster` : 참여인력 명부(성명·직급·참여율·참여기간·상태)
- **정합성 자동 점검** : 참여율 합계 100% 초과 인력 자동 검출
  > 현재 데이터에서 **2명 검출** (함정영 180%, 최규태 165%). 인건비 중복계상에 해당하므로 참여율 재산정 및 사업계획 변경(참여인력 변경) 절차가 필요합니다. 보고서 Ⅴ장과 붙임 3에 자동 표기됩니다.

### 2.5 UI

다크테마·이모지를 제거하고 공공기관 문서 톤(백색 배경 · 남색 강조 · 관인부 헤더)으로 전환했습니다.

## 4. 배포 절차

### 4.1 보고서 시스템 (`Asan-Report-Generator`)

```bash
git clone https://github.com/LEESUNGHO-AI/Asan-Report-Generator.git
cd Asan-Report-Generator

# 기존 index.html 백업 후 교체
mv index.html index.v4.html.bak
cp -r /전달받은경로/index.html  .
cp -r /전달받은경로/js          .

git add -A
git commit -m "feat: 공문서 규격 준거 문서생성 시스템 v5.0 전면 개편"
git push
```

GitHub Pages는 별도 빌드 없이 즉시 반영됩니다.

### 4.2 인력 데이터 (`Asan-HR-Management-Portal`)

```bash
cd Asan-HR-Management-Portal
mkdir -p tools data .github/workflows

cp /전달받은경로/tools/build-hr-json.js          tools/
cp /전달받은경로/.github/workflows/hr-json.yml   .github/workflows/

node tools/build-hr-json.js index.html data/hr.json   # 최초 1회 수동 생성

git add -A
git commit -m "feat(data): hr.json 엔드포인트 신설 및 자동 생성 워크플로 추가"
git push
```

배포 후 다음 주소가 응답하면 정상입니다.
`https://leesungho-ai.github.io/Asan-HR-Management-Portal/data/hr.json`

> hr.json이 없어도 시스템은 HTML 폴백으로 동작하며, 화면 데이터 원천 카드에 `대체(HTML)`로 표시됩니다.

## 6. 후속 조치 권고

1. **재원별 실계정 집행자료 연계** — 현행 안분 추정치는 정산·감사 부적합. BMS에 재원별 집행 컬럼 추가 필요
2. **참여율 100% 초과 인력 2명 정정** — 인건비 중복계상 방지, 참여인력 변경승인 절차 병행
3. **문서번호 체계 확정** — 현재 `제일엔지니어링스마트시티-2026-0001` 임의 부여. 사내 문서등록대장 체계와 일치시킬 것
4. **결문 실제값 확정** — 대표이사 성명, 대표전화·전송·업무메일은 임의 생성값이므로 실제값으로 교체 필요 (설정 패널에서 수정 가능)
5. **미배치 자산 99점 배치 확정** — 중요재산 7건 전부 설치위치 `미배치` 상태. 정산 전 실사·배치 확정 필요
